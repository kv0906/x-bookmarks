# OpenAI Codex

OpenAI's terminal-native coding agent environment, centered on TUI workflows, structured tool use, and a growing plugin/MCP ecosystem. The bookmarks here show Codex maturing in two directions at once: broader external integrations and better visibility into long-running agent execution.

## Key Points
- **Plugins and MCP** make Codex extensible beyond the codebase, reaching tools like Slack, Figma, Notion, and Gmail through a common interface
- **Codex 0.120.0** improves live agent observability with background progress streaming, clearer hook activity in the TUI, and stronger structured tool-output support
- The direction of travel is clear: terminal UX, typed tool results, custom servers, and streaming agent state are becoming as important as raw model capability
- Codex now belongs to the same ecosystem shift as [[claude-code]], where portability of skills, hooks, and protocol integrations matters more than single-vendor lock-in
