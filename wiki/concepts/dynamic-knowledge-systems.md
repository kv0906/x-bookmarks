# Dynamic Knowledge Systems

Approaches for making AI instructions and knowledge bases self-evolving, where the system reviews, tests, and refines what it knows instead of operating from static prompts. The pattern is expanding from memory and rules into encoded judgment and markdown-native operating systems.

## Key Points
- **Hypothesis-to-rule promotion** remains the core pattern: observe, test, promote, demote
- **Compounding CLAUDE.md** approaches let the agent extract and refine its own working knowledge session over session
- **Agent Lattice (lat.md)** applies the same idea to codebases with markdown-managed knowledge graphs
- **autoDream** shows the memory layer itself can self-edit and self-prune in the background
- **CLAUDE.md as decision engine** reframes config files as knowledge architecture + decision journal + quality gate
- **Lenses** extend the idea from facts to judgment: risk tolerance, delegation style, and "good enough" thresholds can be encoded for agents too
- **Context engineering** marks the evolution from static RAG to agents actively constructing context from files, memory, databases, web, and tools
- **Ronin** shows markdown as an operational brain outside coding: templates, publishing rules, editorial logic, and workflow orchestration can all live in plain files
