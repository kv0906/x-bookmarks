# fireworks-tech-graph

An open-source Claude Code skill that generates production-quality technical architecture diagrams from natural language descriptions. It replaces the manual alignment, styling, and export overhead of traditional diagramming tools with an AI-native text-to-diagram workflow.

## Key Points
- **Natural language to diagram**: describe the system and get a production-ready diagram without learning a DSL or dragging shapes
- **Semantic automation**: diagram type, shapes, colors, and iconography are inferred from the description
- **Agent-aware patterns**: built-in support for RAG, multi-agent, tool-call, Agentic Search, and memory-centric system diagrams
- **Output quality**: SVG plus high-resolution PNG makes the tool useful for docs and presentations, not just quick sketches
- Distributed as a Claude Code skill, making it a strong example of the broader [[agent-skills]] ecosystem
