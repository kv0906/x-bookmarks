## Summary
This bookmark highlights the release of acpx 0.6.0, a command-line interface (CLI) tool designed for controlling AI models like Claude and Codex through agents. The update introduces significant improvements for AI developers, focusing on better control over model prompts, session management, and overall usability. ## Key Insights

- Version 0.6.0 introduces `--system-prompt` and `--append-system-prompt` global flags for precise control over AI model's initial instructions, accessible via `_meta.systemPrompt` on session initialization.
