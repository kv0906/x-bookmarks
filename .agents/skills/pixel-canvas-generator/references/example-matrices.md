# Example Pixel Matrices

Hand-drawn matrices for common icons. Each is an 8x8 grid.
`1` = filled pixel, `0` = empty.

## Usage

```typescript
import { PixelCanvas } from './PixelCanvas';

const heartIcon = {
  matrix: [/* heart matrix above */],
  colors: ['#FF007A', '#FF6000', '#FFD600'],
};

<PixelCanvas
  matrix={heartIcon.matrix}
  colors={heartIcon.colors}
  pixelSize={8}
  gap={2}
  animate={true}
/>
```
